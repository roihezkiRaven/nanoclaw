# WhatsApp Brain assets

These non-secret assets are deployed to a dedicated Luna-powered WhatsApp Brain group. The daily pass reads only the collector's allow-listed raw-message archive and maintains substantive, source-grounded, group-isolated digests below the WhatsApp wiki subtree. A slower brain pass then deduplicates those daily pages into durable cross-group AI-learning pages under `whatsapp/brain/`. Neither pass promotes WhatsApp facts into the Timeless graph.
