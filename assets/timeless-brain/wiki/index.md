# Timeless Knowledge

Source-grounded, durable knowledge distilled from the owner's Timeless Drive folder.
This is an index and graph entry point, not a transcript archive.

## Topic map

- People: `people/`
- Projects: `projects/`
- Decisions: `decisions/`
- Tasks and commitments: `tasks/`
- Recurring themes: `topics/`

## Rules

- Every factual page links to one or more Drive sources.
- Keep one concept per page and link related concepts in both directions.
- Prefer updating a page to creating a duplicate.
